### 🚀 Framework de Contribución (DX-Focused)

¿Buscas elevar el estándar de las herramientas abiertas de observabilidad junto
a nosotros? Incentivamos una **Developer Experience (DX)** superior:

- **Arquitectura Edge-Native:** Desarrollo sobre Deno 2, Deno KV y Fresh con
  Preact Islands.
- **Calidad de Código y Tipado:** Estricto 100% TypeScript con 0 tipos `any`,
  formateo nativo (`deno fmt`) y linter auditado (`deno lint`).
- **Cultura DevSecOps & AppSec:** Principio de menor privilegio (PoLP) en GitHub
  Actions, análisis estático continuo con CodeQL, validaciones estrictas contra
  inyecciones y comparaciones criptográficas en tiempo constante (timing-safe).
- **Cobertura de Pruebas:** Toda nueva funcionalidad o servicio debe acompañarse
  de tests unitarios ejecutables mediante `deno test --unstable-kv -A`.

Aplicamos flujos de revisión de código rigurosos basados en mantenibilidad a
largo plazo, alta disponibilidad y rendimiento edge sub-milisegundo.
